# ahmetcanyesildag.com

Personal authority site of Ahmet Can Yeşildağ — hospitality executive, Orophile founder, and Cornell MMH alum.

**Live:** https://ahmetcanyesildag.com
**Stack:** Static HTML/CSS (Webflow export) → Netlify (GitHub-connected deploy)

## Structure

- `index.html` — Homepage
- `orophile.html` — Orophile brand page
- `books.html` — Reading Room
- `blog.html` — Articles
- `media.html` — Press & media
- `documents.html` — Resume & decks
- `toolkit.html` — Curated affiliate toolkit
- `404.html` — Branded 404
- `css/site.css` — External stylesheet (extracted from inline)
- `netlify.toml` — Redirects, headers (HSTS, CSP), cache rules
- `sitemap.xml` · `robots.txt` — SEO
- `images/` — Photography assets
- `documents/` — PDFs

## Deploy

Connected to Netlify via Git. Every push to `main` auto-deploys.

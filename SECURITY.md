# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Contact:** ahmetcan@ahmetcanyesildag.com

Please include a description of the vulnerability, steps to reproduce it, and any potential impact. I will acknowledge receipt within 48 hours and work to address the issue promptly.

## Scope

This policy applies to the source code and deployment of [ahmetcanyesildag.com](https://ahmetcanyesildag.com).

## Supported Versions

Only the latest version deployed on the `main` branch is actively maintained.
